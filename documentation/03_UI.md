# 4. SYSTEM STATUS

## 総合ステータス

```
SYSTEM STATUS
──────────────────────────

SCORE      □□ ■□
PHASE      ATTACK
NETWORK    41 NODE
```

表示内容

* プレイヤースコア/CPUスコア
* 現在の攻撃権
* ラウンド状態

```

```

```

[■■□]

CPU

[■□□]
```

## 攻守表示

```

```

# 5. NETWORK FIELD

## コンセプト

アメフトのフィールドではなく、

「敵メインフレームへ侵入するネットワーク経路」

として表示する。

---
## 概要

## 初期状態

41ノード。

表示例

```
ATTACKER LP   : 08/10

LOCAL CORE                                      REMOTE CORE

[00]═══◇═══10═══20═══●═══30═══[40]

AGENT POSITION: NODE 25|REM:15|
LP RECOVERY   : NODE 30|REM:05|
```
## 表示項目

●：Agent

◇：LIFE RECOVERY POINT

AGENT POSITION　→エージェント位置、残りノード数

LP RECOVERY　→　LP回復ポイント、残りノード数

記号は全角、NODE10,20,30を表記

ノード番号を表記する。

PlayerのCOREが「00」番、CPUのCOREが「40」番

縮小(後述)後に振り直さない。

---

## フィールド縮小

```
縮小後：

NETWORK RANGE

NODE 02 - NODE 38

WARNING
PERIMETER COLLAPSED
```

さらに、

```
SEALED NODE : 00-01
SEALED NODE : 39-40

のようなログを出す。
```

などの演出を表示。

つまり、封鎖されたノードはCOREまでバイパスされてしまう。

# 10. カード残量表示

```
BLITZ-02   x04

```

```
> ABFANG-02 DETECTED

> PROGRAM INTERRUPTED

> AGENT ADVANCE : 0 NODE
```

# 12. プログラム実行演出

カード使用時、

コンソール上にカットイン表示。

流れ：

1. プログラム選択

2. ロード表示

```
LOADING...
```

3. 実行

```
EXECUTING STURM-08
```

4. 結果表示

```
ADVANCE +8 NODE
```

# 16. UI設計思想

カードゲームとしての分かりやすさと、

「未来の軍用端末を操作している感覚」

を両立する。

情報量は多く見せるが、

重要情報は以下に集約する。

* 現在位置
* LP
* 使用可能カード
* 相手の残存プログラム
* COREまでの距離
