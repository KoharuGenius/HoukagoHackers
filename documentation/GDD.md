# 1. ゲーム概要

## ジャンル

対戦型ブラウザカードゲーム

## コンセプト

「サイバー戦争」を題材にしたオリジナルカードゲームを、中学生のカードゲーム部が放課後に真剣に遊ぶ作品。

プレイヤーは電子戦の司令官となり、侵入プログラムと防御プロトコルを駆使して敵メインフレームへの侵入を目指す。

本格的なサイバーパンクSFと、女子中学生の日常とのギャップを作品の魅力とする。

## info
劇中ゲーム名：NexusFrontier

作品タイトル：放課後はっかーず！

### 世界観の二重構造

表：カードゲーム部の放課後

裏：電子戦シミュレーション「NexusFrontier」

UIコンセプト：レトロ軍用コンソール

カード表現：漢字＋ドイツ語ルビ＋プログラム型番

---

# 2. 開発目標

* シンプルなルールで奥深い読み合いを実現する
* 1試合5〜10分程度で遊べるテンポ
* 実況・配信映えする演出
* ブラウザのみで動作する
* PC・スマートフォンの両対応

## 設計思想
* シンプルだが読み合いが深いこと
* レトロコンソールUIで世界観を演出すること
* サイバーパンク設定と放課後の日常のギャップを楽しむこと
* 実況・配信で状況が伝わりやすいこと

HTML・CSS・JavaScriptによるブラウザゲームとして開発する。

UIはコンポーネント化し、
カード・ダイアログ・ネットワーク表示などを再利用可能な構成とする。

# 10. 開発方針

本プロジェクトでは、

「まず遊べるものを作る」

ことを最優先とする。

過度な機能追加は避け、
コアとなるゲームシステム・UI・演出を磨き上げる。

仕様変更は **DecisionLog.md** に記録し、
設計変更の経緯を残す。
